## Про що цей проєкт?

**«Самостійні»** — це легкий, швидкий та бекенд-незалежний інструмент для вчителів і учнів. Він дозволяє створювати інтерактивні завдання будь-якої складності, проводити їх під час уроку (наживо або дистанційно) та автоматично зберігати оцінки й відповіді у **Google Таблиці**.

Система працює повністю у браузері через **GitHub Pages**, не вимагає платних серверів або складних баз даних!

## Головні можливості

### 1. Багатий набір типів питань
- **Одинарний та множинний вибір** (з авто-перемішуванням відповідей).
- **Блоки «Так / Ні»** для швидкої перевірки теорії.
- **Встановлення відповідностей** (зручне drag-and-drop / select меню).
- **Коротка відповідь** (з інтелектуальною перевіркою синонімів та числових значень).
- **Розгорнута відповідь** з авто-перевіркою за ключовими поняттями/коренями слів.
- **Підпис частин на малюнку (Labeling)** — учень вибирає правильну назву для кожної точки.
- **Вказання точки на малюнку (Tap-to-select)** — інтерактивний вибір координати на зображенні!

### 2. Розумний захист від списування
- **Анти-Копіпаст**: Повна заборона вставки тексту, виділення, перетягування та гарячих клавіш (`Ctrl+C`, `Ctrl+V`, `F12`).
- **Фіксація виходу зі сторінки**: Автоматичний відлік секунд, якщо учень згортає вкладку чи перемикається на месенджери.
- **Одноразове проходження**: Блокування повторної здачі з того ж пристрою.

### 3. Режим «Повітряна тривога» / Пауза
- Вчитель може в 1 клік призупинити тест для всього класу.
- На екранах учнів з'являється оверлей паузи, а **таймер зупиняється**. Після відбою роботу можна продовжити без втрати часу!

## Швидкий старт за 5 хвилин

<details>
<summary><b>Крок 1. Форк та GitHub Pages</b></summary>

1. Зробіть **Fork** цього репозиторію у свій акаунт GitHub.
2. Перейдіть у **Settings** → **Pages**.
3. У розділі **Build and deployment** виберіть `Branch: main` / `/(root)`.
4. Натисніть **Save**. Через 1-2 хвилини ваш сайт буде доступний за адресою:
   `https://<ваш-логін>.github.io/<назва-репо>/editor.html`
</details>

<details>
<summary><b>Крок 2. Налаштування Google Apps Script (Бекенд)</b></summary>

1. Створіть нову [Google Таблицю](https://sheets.new).
2. Перейдіть у **Розширення** → **Apps Script**.
3. Вставте код з файлу `Code.gs` даного репозиторію.
4. Вкажіть свій власний **TEACHER_PIN** (наприклад, `"4321"`).
5. Натисніть **Deploy** → **New deployment** → Виберіть тип **Web app**:
   * *Execute as:* **Me**
   * *Who has access:* **Anyone**
6. Скопіюйте отриманий **Web App URL** та впишіть його у файл `config.js`:
   ```javascript
   window.SCRIPT_URL = "https://script.google.com/macros/s/.../exec";
   ```
</details>

<details>
<summary><b>Крок 3. Створення та запуск першої роботи</b></summary>

1. Відкрийте `editor.html` у своєму браузері.
2. Введіть свій ПІН-код.
3. Натисніть **«Імпорт з файлу»** та завантажте будь-який тест з папки `tests/` або створіть власний.
4. Натисніть **«Видача»**, скопіюйте посилання або покажіть учням **QR-код** з екрана!
</details>

## Технологічний стек

- **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, Grid), Pure Vanilla JavaScript (ES6+).
- **Backend:** Google Apps Script (REST API via POST/GET).
- **Storage:** Google Drive & Google Sheets API.
- **Libraries:** `qr-lite.js` (автономний генератор QR-кодів без зовнішніх залежностей).
